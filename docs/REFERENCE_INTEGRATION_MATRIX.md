# Reference Integration Matrix

| Category | TECH360 equivalent | Decision |
|---|---|---|
| CRM/ERP references | Unified Client ID, leads, projects, invoices, payments, portal | Native implementation; do not import another CRM |
| Marketing/SEO kits | Content Studio marketing kit and SEO brief | Integrated and persisted |
| Diagram design | Responsive English SVG/HTML infographics | Integrated natively |
| Agent/memory/knowledge tools | Agent registry, executions, memory and governed knowledge | Native implementation; continue security tests |
| Video/image/audio projects | Scripts, prompts, storyboards and provider-neutral planning | Rendering blocked pending licensed provider/credentials |
| VoIP/desktop/OS/developer tools | Different product category | Not integrated |
| Payment providers | Stripe built; manual methods governed; PayPal/SSLCommerz unbuilt | Require approved provider specification and sandbox credentials |
| Messaging/social providers | Adapters and webhooks present | Live verification blocked by credentials/consent |

Per-reference dispositions remain in `COVERAGE-AUDIT.md`; license/access evidence is incomplete and must be extended incrementally.
